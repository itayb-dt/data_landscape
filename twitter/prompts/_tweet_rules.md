# Rules for every thread

Read these before writing. They apply to every prompt in this folder.

1. **Source of facts:** only the article the thread is about. No new facts, numbers or claims. If the article does not say it, the thread does not say it.
2. **The writing rules apply:** read `product/prompts/_writing_rules.md`. No research-process wording, nothing that reads as AI-written, no em dashes.
3. **Length:** each post is 280 characters or fewer. A link counts as 23 characters. Count before you present it.
4. **Post 1:** the news in one or two plain sentences, then the link to the article. A reader who sees only this post should understand what happened.
5. **The author's view:** write it only when the article has a My Take, and phrase it as the author's opinion ("I think"). Never invent an opinion.
6. **No hashtags, no emojis, no "thread" or "1/" announcements like "A thread:"**. Number the posts as `1/`, `2/` only if there is more than one.
7. **Do not talk about the site in general** (no "my blog", "my site", "I write about"). The thread is about the news, and the link is the only mention. Remove this rule only when the author says so.
8. **Names:** use the company names as in the article. Do not tag accounts.
9. **Length of thread:** 1 to 3 posts. Two or three is the default. One post only when the news is simple.
10. **After writing, tell the author** which claims in the thread rest on a single source or on an opinion, so the author can check them before posting. Keep that out of the thread itself.
